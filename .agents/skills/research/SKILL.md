# Research Skill

Use this skill when the user requests research, fact finding, comparisons or source analysis.

---

# Research process

Follow:

```text
Understand question
→ identify subquestions
→ gather sources
→ evaluate sources
→ extract evidence
→ synthesize
→ identify uncertainty
→ produce result
```

---

# Sources

Prefer:

1. primary sources
2. official documentation
3. academic papers
4. reputable organizations
5. reputable journalism

Avoid relying on low-quality sources when stronger sources exist.

---

# Source handling

Track:

* source URL
* title
* publication date
* author/organization
* relevant evidence

---

# Claims

Distinguish:

* verified fact
* inference
* estimate
* opinion
* unresolved claim

Never present uncertain information as established fact.

---

# Research output

For substantial research provide:

* concise answer
* key findings
* supporting evidence
* sources
* uncertainty
* recommended next steps when appropriate

---

# User context

Use relevant MIND memories and documents.

Do not use unrelated personal information.

---

# Save to memory

Research findings should not automatically become permanent memory.

Save only information with clear long-term value.
